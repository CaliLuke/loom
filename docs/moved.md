# Moved!

The current source of truth is now the [Loom repository](https://github.com/CaliLuke/loom).

Loom is a fork of Goa that has diverged toward AI-first API development,
better machine-consumable OpenAPI 3.1 contracts, and the framework work needed
to build Auto-K cleanly. If you are looking for the actively developed fork
that prioritizes stronger generated specs, direct client generation, JSON-RPC,
streaming, and AI-assisted workflow support, this is it.

For install instructions, use:

```bash
go install github.com/CaliLuke/loom/v3/cmd/loom@latest
```
