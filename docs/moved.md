# Moved!

The current source of truth is now the [Loom repository](https://github.com/CaliLuke/loom).

Loom has evolved toward AI-first API development, better machine-consumable
OpenAPI 3.1 contracts, and framework-owned transport/codegen behavior that
keeps application design files smaller.
If you are looking for the actively developed framework that prioritizes
stronger generated specs, direct client generation, JSON-RPC, streaming, and
AI-assisted workflow support, this is it.

For install instructions, use:

```bash
go install github.com/CaliLuke/loom/cmd/loom@latest
```
