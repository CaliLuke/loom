## Accepted contract and proposed boundary

A named validation occurrence must resolve the same physical identity as its
registered declaration. Authored protocol naming metadata survives that edge;
occurrence-only nullability and local constraints must not redefine the intrinsic
named parameter carrier. Keep the shared resolver and package collectors as the
owners. Do not duplicate protobuf name lookup in validation, patch emitted text,
rename declarations after generation or strip author metadata to make names fit.

Existing #709 models abstract physical identity agreement. The new finite model
will expose the lost-metadata counterexample and check agreement for explicit
and default names, independent declaration order, and intrinsic versus
occurrence-only presence. Generated code and direct seam tests must establish
correspondence; the model cannot prove Go naming or metadata traversal.
