# HTTP Transport IR Decoupling Plan

Make `/Users/luca/code/loom-mono/loom/http/codegen/internal/transportir` the only owner of transport semantics for HTTP codegen and route-scoped OpenAPI operation generation. The governing heuristic for every milestone in this plan is: if code needs to answer an HTTP transport question, it should answer it from `transportir`, while `expr` may remain only as a source of type/schema handles and not as a source of transport structure. In this plan, “transport semantics” means route identity, request parameter/security projection, request body origin and requiredness, response status/body publication, response headers and cookies, error identity/remedy metadata, and stream handshake metadata. After this pass, HTTP and OpenAPI consumers may still consume `*expr.AttributeExpr`, result-type view metadata, validation metadata, and examples as type/schema handles, but they must stop reading transport structure from `expr.HTTPEndpointExpr`, `expr.RouteExpr`, `expr.HTTPResponseExpr`, `expr.HTTPErrorExpr`, `expr.MappedAttributeExpr`, and `expr.HTTPResponseCookieExpr` outside `transportir`, the exported `BuildDocument` and `BuildRouteOperation` wrappers, the route-scoped caller in [`openapi/v3/builder.go`](/Users/luca/code/loom-mono/loom/http/codegen/openapi/v3/builder.go), and the explicitly out-of-scope helpers listed in this plan. Remove dead private compatibility wrappers and the unused exported `BuildOperation` test seam instead of preserving them. The chosen contract for this pass is: keep `*expr.AttributeExpr` handles for payload/result/body/message typing only; remove `Request.RawStreamingBody`; replace raw response headers, cookies, error identity, and remedy data with IR-owned value objects; and move route selection into `transportir` so `BuildRouteOperation` becomes a thin wrapper.

## Scope

In scope: `/Users/luca/code/loom-mono/loom/http/codegen`, `/Users/luca/code/loom-mono/loom/http/codegen/openapi/internal/ir`, route-scoped OpenAPI callers in `/Users/luca/code/loom-mono/loom/http/codegen/openapi/v3`, and any dead private wrappers in `/Users/luca/code/loom-mono/loom/http/codegen/openapi/internal`.

Out of scope: helper-only raw-type usage in [`typedef.go`](/Users/luca/code/loom-mono/loom/http/codegen/typedef.go) and schema-href generation in [`json_schema.go`](/Users/luca/code/loom-mono/loom/http/codegen/openapi/json_schema.go), because those do not own HTTP transport semantics in this pass.
