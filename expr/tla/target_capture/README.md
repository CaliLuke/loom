# Reusing a captured representation target

`TargetCapture` checks the boundary between mutable caller attributes, an owned
target capture, and independently configured plans. It informed
`ValuePlanRequest.TargetOccurrence` and the normalized ancestry stored by
`valueOccurrenceNode`. The compiler design is in `codegen/COMPILATION.md`.

The finite model has two target versions, two policies and two contexts. Capture
and raw mutation can happen in either order. All four plan requests must finish;
foreign-context requests are rejected. Construction is atomic and weak fairness
of the finite `Next` relation supplies completion. Terminal deadlock checking is
disabled. No callback, concurrency, allocation size or recursive graph is modeled.

## Results

- `Captured.cfg`: snapshot stability, context isolation, policy independence and
  completion pass; 132 generated states, 62 distinct states, depth 7.
- `Mutable.cfg`: rereading raw state after capture violates `SnapshotStable`;
  10 generated/distinct states, depth 4.
- `Foreign.cfg`: admitting a foreign capture violates `ContextIsolated`;
  6 generated/distinct states, depth 3.
- `Policy.cfg`: retaining one policy result for both consumers violates
  `PolicyIndependent`; 16 generated, 15 distinct states, depth 4.

The negative controls model unsafe reuse designs. The existing raw-target API
intentionally captures on every call; that behavior is not itself a violation.
The Go regression first failed because captured-target requests were not admitted.
It also requires stable root/source/descendant ancestry after caller mutation.

## Reproduce

Use official TLA+ v1.7.4 `tla2tools.jar` (TLC 2.19), SHA-256
`936a262061c914694dfd669a543be24573c45d5aa0ff20a8b96b23d01e050e88`.
Verified with Corretto Java 25.0.4.1. From this directory:

```sh
java -Xmx512m -cp "$TLA_JAR" tlc2.TLC -workers 1 \
  -metadir "$TLC_STATE" -config Captured.cfg TargetCapture.tla
```

Repeat for `Mutable.cfg`, `Foreign.cfg` and `Policy.cfg`; require the named
invariant counterexamples, not parser/type/resource failures. Keep checker state,
jar and logs outside the repository and remove task-owned output after review.

## Correspondence and limits

`expr/value_plan_capture_test.go` checks capture admission, frozen ancestry,
shape, independent codecs and includes a width-scaling allocation benchmark.
`expr/value_source_binding_test.go` retains malformed ancestry rejection.
HTTP representation planning shares its final target capture between schema,
anchor and example plans; different source contexts require separate captures.
Existing OpenAPI hidden-field, default, recursion, view and custom-codec tests
guard effects that this small model omits. Generated bytes and compilation must
also match a representative baseline.

Sharing does not make opaque/custom Go values immutable. Their existing borrowed
source and target-materialization contracts remain in force. The model does not
prove memory bounds, source/target mapping correctness or output equivalence.
